A fix for a hang when switching tabs, plus editing in the preview, deep links and pasted images.

**Fixed**
- Switching tabs could hang the app for good when one of the documents was longer than the window (seen on macOS 26 and 27). Switching is instant again, whatever the documents' lengths and wherever they were scrolled.
- Switching tabs now closes the find bar of the document that left: Replace All could otherwise change the next document at the wrong places.
- Spelling corrections still on their way no longer land in the document you switched to.
- A closed window now releases everything it held.

**Editing in the preview**
- Click into text in the preview and type: the Markdown source changes with it, input methods included. Markdown syntax you type there is escaped, so it stays text.
- Selecting in the editor highlights the same text in the preview, and selecting in the preview highlights it in the editor.
- In a task list, clicking the item's text places the caret; only the checkbox ticks it.

**Editor**
- Paste a screenshot or an image: it is saved next to the document in `images/` and linked as `![image](images/…)`.
- Settings ▸ Editor ▸ Scroll past the end (off by default).
- Your own editor themes: JSON files in `~/Library/Application Support/MacDown2/Themes/` appear in the theme list and update when changed.

**Links and Quarto**
- `macdown2://open?path=…&line=…` opens a file at a line, and `macdown2://workspace?path=…` opens a folder as a workspace (for scripts, browsers and other apps).
- Quarto: Pandoc's blank-line rules are followed, and code cells in Python, R and YAML are highlighted.
