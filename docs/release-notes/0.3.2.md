A fix for the editor losing its place, and a layout switch you can see at a glance.

**Changed**
- The toolbar's layout button is now a three-part control: click Editor and Preview, Editor Only or Preview Only to go straight to it, instead of cycling. ⌃⌘L still cycles.
- New windows start with the layout you last chose. Settings ▸ Startup Layout follows your last choice, and a workspace folder still reopens with its own last layout.

**Fixed**
- Changing the zoom level or the editor theme while scrolled into a document no longer moves the editor somewhere else: the line at the top stays at the top, also while an input method is composing, and scrolling right afterwards is no longer pulled back. Thanks to @alphataubio for reporting it and for the first fix (#89).
