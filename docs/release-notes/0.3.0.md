Quarto documents rendered by Quarto itself, and search powered by qmd.

**Quarto**
- View ▸ Render with Quarto (⌥⌘R), or the Approximate | Quarto switch above the preview, shows a `.qmd` the way your local Quarto renders it (Quarto 1.4 or later; found on your shell's PATH, or set its path in Settings ▸ Extensions ▸ Quarto). The preview updates each time you save.
- Nothing runs on its own: the first time, MacDown2 asks before Quarto executes the document's code. For a document inside a Quarto project, the question names the project, since rendering it can run the project's other documents and filters too.
- Switching back to the approximate preview, closing the document or quitting stops Quarto at once.

**qmd search (optional, off by default)**
- Turn it on in Settings ▸ Extensions to search a workspace with [qmd](https://github.com/tobi/qmd) (`npm i -g @tobilu/qmd`). Keyword results appear as you type; the built-in search still answers when qmd cannot.
- MacDown2 asks before adding a folder to qmd's index, and keeps its collections out of your own default qmd queries.
- Semantic search: turning it on downloads qmd's models (about 1.6 GB) and indexes the folder in the background, with progress and Cancel; the sparkles button is ready once that is done. Results highlight whole words.

**Also**
- A window with no open file now shows its top strip in the editor theme's colours.
- Faster preview editing and scrolling on long documents, and a broad internal clean-up.
