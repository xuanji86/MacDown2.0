The first public release of MacDown2.0, a native Markdown editor for macOS 26 rebuilt from zero in Swift and SwiftUI, in the spirit of MacDown.

**Writing**
- The classic two panes: a dark editor (tree-sitter highlighting, MacDown's shortcuts and toolbar) beside a live preview that scrolls in sync.
- Tick a task box in the preview and the Markdown source changes with it.
- GFM, footnotes, GitHub alerts, KaTeX math, highlight.js code, Mermaid diagrams, YAML/TOML front matter, CJK-aware emphasis.
- Quarto `.qmd` files get an approximate preview (built-in extension, code is never executed).

**Workspace**
- Open a folder as a workspace: Finder-style file tree, tabs, full-text search (⇧⌘F) and an outline in the sidebar.
- Click the active tab's name to rename, tag or move the file.
- Files changed by other programs reload by themselves; UTF-8, UTF-16, GB18030, Shift_JIS, Windows-1252 and Mac Roman are read and written faithfully.

**Output**
- Export to single-file HTML or paginated PDF, print, or copy as HTML; all sanitized.
- `macdown2` command-line tool: open files and folders, or render HTML / PDF without starting the app.
- Quick Look previews in Finder.

**And** English and Simplified Chinese UI, 7 editor and 8 preview themes, five Dock icon styles, and Sparkle updates from this release on.

Requires macOS 26 or later; one universal build for Apple Silicon and Intel.
