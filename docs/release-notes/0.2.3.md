Zoom, a manual render mode, and new notes straight from a link.

**View**
- View ▸ Zoom In (⌘+ or ⌘=), Zoom Out (⌘−) and Actual Size (⌘0) scale the editor and the preview together, from 50 % to 300 %. The level is remembered; the font size in Settings stays the base.
- Format ▸ Paragraph moves to ⌥⌘0 to make room for Actual Size.

**Preview**
- Settings ▸ Rendering ▸ Update preview automatically (on by default). Turn it off and the preview waits for View ▸ Render Preview (⌘R); the word and character counts in the status bar still follow your typing.
- ⌘R re-renders the preview at any time, also picking up images in the document's folder that changed on disk.
- Click a link to a Markdown file that doesn't exist yet, in the document's folder or a folder below it, and MacDown2 offers to create it and opens it in a new tab. Links that leave the document's folder are never created.
