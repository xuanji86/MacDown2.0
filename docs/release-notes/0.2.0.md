A much faster preview, and a website.

**Faster preview**
- The preview now re-renders only the sections you changed and patches them into the page. On an Apple M5 Pro a keystroke updates a 1 MB document in about 7.5 ms (was about 65 ms), a document with 200 formulas in about 4 ms, and 300 code blocks in about 4 ms. MacDown 0.7.3 takes 78.5, 495 and 48 ms for the same documents.
- No more 150 ms wait after you stop typing: the preview renders on the next display frame.
- Formulas, highlighted code and Mermaid diagrams that didn't change are reused instead of drawn again.
- Fixed: the preview could randomly rebuild the whole page instead of patching it, losing its scroll state and hover.
- Fixed: certain GitHub alert (`> [!WARNING]`) layouts shifted the source-line mapping of everything below, and one could hang the preview.

**Interface**
- The active tab's name is readable again when a dark editor theme is used in light mode.
