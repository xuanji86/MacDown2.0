技术

建在现代 Mac 技术栈上的原生 Markdown 编辑器。

MacDown2.0 与 MacDown 共享的是一种理念，而不是代码。每一层都是为今天的 Mac 选的。

Swift 6 + SwiftUI
原生应用代码，使用 Swift 6 语言模式与严格并发检查，界面用 SwiftUI 编写。

实时预览的速度：实测，不是承诺。

一次编辑之后更新预览所需的时间（含布局），与 MacDown 0.7.3 对比，越低越好。

命令行

macdown2：在终端里把 Markdown 渲染成 HTML 与 PDF。

在应用里打开文件和文件夹，或者无头渲染 HTML 与 PDF，不需要窗口，也没有 Dock 图标。Homebrew cask 会帮你装好。

zsh
$ macdown2 notes.md docs/# 文件夹以工作区打开
$ macdown2 .# 当前文件夹
$ cat draft.md | macdown2# 打开管道输入
$ macdown2 render a.md --standalone -o a.html# 无头渲染
$ macdown2 render a.md --export pdf -o a.pdf# 无需窗口
