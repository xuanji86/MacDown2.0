Technology

A native Markdown editor on the modern Mac stack.

MacDown2.0 shares an idea with MacDown, not its code. Every layer was chosen for the Mac of today.

Swift 6 + SwiftUI
Native app code in Swift 6 language mode with strict concurrency, an interface written in SwiftUI.
language · UI
TextKit 2
The editor runs on Apple’s current text engine.
editor
tree-sitter
Incremental syntax highlighting: an edit re-parses only what it touched.
highlighting
markdown-it, incremental
The preview re-renders only the sections you changed and patches them into the page, never reloading it.
renderer
macOS 26
Made for the current release: Liquid Glass and five Dock icon styles.
platform
Universal binary
Runs natively on Apple Silicon (M1 to M5), no Rosetta; the same download runs on Intel. Sparkle handles updates.

Command line

macdown2: Markdown to HTML and PDF from the terminal.

Open files and folders in the app, or render HTML and PDF headless, without a window or a Dock icon. The Homebrew cask installs it for you.

zsh
$ macdown2 notes.md docs/# a folder opens as a workspace
$ macdown2 .# this folder
$ cat draft.md | macdown2# open piped text
$ macdown2 render a.md --standalone -o a.html# headless
$ macdown2 render a.md --export pdf -o a.pdf# no window
