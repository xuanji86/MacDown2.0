Command line命令行

macdown2: Markdown to HTML and PDF from the terminal.macdown2：在终端里把 Markdown 渲染成 HTML 与 PDF。

Open files and folders in the app, or render HTML and PDF headless, without a window or a Dock icon. The Homebrew cask installs it for you.在应用里打开文件和文件夹，或者无头渲染 HTML 与 PDF，不需要窗口，也没有 Dock 图标。Homebrew cask 会帮你装好。

zsh
$ macdown2 notes.md docs/# a folder opens as a workspace# 文件夹以工作区打开
$ macdown2 .# this folder# 当前文件夹
$ cat draft.md | macdown2# open piped text# 打开管道输入
$ macdown2 render a.md --standalone -o a.html# headless# 无头渲染
$ macdown2 render a.md --export pdf -o a.pdf# no window# 无需窗口
